## 二、界面分四个区

| 区 | 内容 | 说明 |
|---|---|---|
| ① 状态信息 | 网络状态 / IP配置类型 / MAC地址 / VISA地址 | 只读，用来判断配没配好 |
| ② 参数值 | IP地址 / 子网掩码 / 默认网关 / DNS服务器 | 要填的就是这里 |
| ③ 配置类型 | DHCP / 自动IP / 静态IP | 三个勾选框，**互相独立** |
| ④ 右侧菜单键 | 配置类型 / IP地址 / 子网掩码 / 网关 / DNS / 应用 / 初始化 | 对应前面板右侧软键 |

**网络状态可能出现的提示**：
`网络配置成功!` / `获取IP中…` / `IP冲突!` / `未连接!` / `DHCP配置失败!` / `读取状态失败!`

## 三、三种配置类型

| 类型 | 行为 | 何时用 |
|---|---|---|
| **DHCP** | 由局域网里的 DHCP 服务器分配地址 | 接到路由器/公司网络 |
| **自动IP** | 自动取 `169.254.0.1 ~ 169.254.255.254`，掩码 `255.255.0.0` | **直连笔记本且没有 DHCP 时** |
| **静态IP** | 全部参数自己填 | 需要固定地址时 |

> ⚠️ **官方明确写的坑（p243）**：
> 三个类型同时开启时，优先级是 **DHCP > 自动IP > 静态IP**。
> 所以想用静态IP，**必须手动把 DHCP 和 自动IP 的勾取消掉**，否则静态IP 形同虚设。
> 另外：三个**不能同时全关**。

## 四、两个旋钮分工不同（别搞混）

前面板说明（Table 1-1）：

| 编号 | 名称 | 作用 |
|---|---|---|
| **3** | 多功能旋钮 | 在菜单里**改数值 / 选参数**；**按下去 = 确认** |
| **5** | 导航旋钮 | **快速定位 / 跳转**参数位置 |

手册菜单图标说明（p1-21）：
- 🔄 *旋转多功能旋钮调整参数，然后按下旋钮选中该参数*
- 旋转导航旋钮可快速定位/跳转参数

**对应到 IP 地址输入**：
- 改数值 → **多功能旋钮**（转）
- 换到下一段（`169` → `254` → `43` → `112`）→ **导航旋钮**，或左右方向键
- 确认 → **按下多功能旋钮**

## 五、填参数

| 项目 | 格式 | 范围 |
|---|---|---|
| IP地址 | `nnn.nnn.nnn.nnn` | 第 1 段 1–223（不含 127），后 3 段 0–255 |
| 子网掩码 | `nnn.nnn.nnn.nnn` | 每段 0–255 |
| 默认网关 | `nnn.nnn.nnn.nnn` | 自动IP / 静态IP 模式下可设 |
| DNS服务器 | `nnn.nnn.nnn.nnn` | 一般不用填 |

- `应用` = 让当前参数生效（**必须按，不按不生效**）
- `初始化` = 恢复默认网络参数
- `mDNS` = 开关多播域名服务（小网络无 DNS 时的服务发现）

## 六、本机实测补充（2026-09-20）

| 项 | 值 |
|---|---|
| 型号 | DS2102E |
| 序列号 | DS2D2023XXXXXX |
| 固件 | 00.03.05.SP4 |
| MAC | 00-19-AF-XX-XX-XX |
| 本机地址 | `169.254.x.y`（自动IP，掩码 255.255.0.0） |
| SCPI 端口 | 5555（裸 socket） |

**重要观察**：自动IP 分配出的地址是**由 MAC 推导的，每次都一样**——
`169.254.x.y` 在多次重新配置后重复出现，所以**直连场景下不设静态IP 也够用**，
地址天然稳定。直连场景下可以不设静态 IP（本仓库发布时对本机实测地址做了打码）。
